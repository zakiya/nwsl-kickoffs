# NWSL-kickoffs

## Requirements

- [Quarto](https://quarto.org/docs/get-started/) — to build and preview the site
- [uv](https://docs.astral.sh/uv/) — to run `update_schedule.py` (manages Python and dependencies automatically)

## Basic development flow

- Edit source files
  - `update_schedule.py` 
  - `styles.css`
  - `head.html`
  - `scripts.html`
  - `index.qmd` Front matter and FAQs only. The rest of the page is generated by update_schedule.py

- Run `uv run update_schedule.py && quarto render` to generate `index.qmd`, `schedule.qmd`, and _`site`

- Preview the site with `quarto preview`
