# NWSL-kickoffs

## Requirements

- [Quarto](https://quarto.org/docs/get-started/) — to build and preview the site
- Python 3.10+ — to run `update_schedule.py`
- Python dependency: `pip install requests`

## Basic development flow

- Edit source files
  - `update_schedule.py` 
  - `styles.css`
  - `head.html`
  - `scripts.html`
  - `index.qmd` Front matter and FAQs only. The rest of the page is generated by update_schedule.py

- Run `source .venv/bin/activate && python3 update_schedule.py && quarto render` to generate `index.qmd`, `schedule.qmd`, and _`site`

- Preview the site with `quarto preview`

## Troubleshooting

ModuleNotFoundError: No module named 'requests' 

```bash
python3 -m venv .venv
source .venv/bin/activate 
pip install requests ## one time
```
